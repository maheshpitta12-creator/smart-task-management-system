# smart-task-management-system
A full-stack productivity management web application developed using React.js and Node.js for task scheduling, prioritization, and real-time task tracking.

## Features
- Add, Edit, and Delete Tasks
- Task Prioritization
- Real-Time Task Status Updates
- User-Friendly Dashboard
- Responsive UI Design
- REST API Integration

## Technologies Used
- React.js
- Node.js
- Express.js
- JavaScript
- REST APIs
- MySQL

## Project Overview
This application helps users organize and manage daily tasks efficiently. The system allows users to create tasks, track progress, and update task status dynamically through a responsive dashboard.

## Future Improvements
- AI-based task prioritization
- Authentication system
- Notifications and reminders
- Cloud deployment
